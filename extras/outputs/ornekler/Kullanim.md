# Herdr Çıktılar

Ajanın paylaştığı dosyaları tek pencerede bul, incele ve paylaş.

> Bu belge ekran görüntüleri için hazırlanmış örnek içeriktir.

## Kurulum

Paketi açıp terminalde şu komutu çalıştır:

```bash
python3 install.py
```

Kurulum mevcut Herdr düzeninin kişisel bir kopyasını oluşturur.

## Dosyalar nasıl açılır?

| Tür | Çift tıklama | Cmd + tıklama |
| --- | --- | --- |
| Görsel | Büyük önizleme | Preview |
| Markdown | Okuma görünümü | Varsayılan uygulama |
| JSON | Açılır-kapanır ağaç | Varsayılan uygulama |
| HTML | Pencere içinde | Chrome |

### Hızlı kullanım

- [x] **Tek tık** ile dosyayı seç.
- [x] **Çift tık** ile pencere içinde aç.
- [x] **Cmd + F** ile belgede ara.
- [ ] İki görseli seçip başka uygulamaya sürükle.

## Örnek veri

```json
{
  "ozellik": "Belge içinde arama",
  "etkin": true,
  "mesaj_sayisi": 50
}
```

**Kurulum** tamamlandıktan sonra üstteki Çıktılar düğmesini kullanabilirsin.
